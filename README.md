# Python Find Maximum and Minimum Element

A simple Python program to find the maximum and minimum elements in an array.

## Author

**Shaik Bhanu**

## Repository Name

`shaikbhanu-python-max-min-array`

## File Name

`max_min_array.py`

## Description

This program accepts an array of numbers from the user and finds both the maximum and minimum elements.

## Features

* Accepts array elements from the user
* Finds the maximum element
* Finds the minimum element
* Uses a simple loop

## Requirements

* Python 3.x

## How to Run

Run the program using:

```bash
python max_min_array.py
```

## Example

```text
Enter number of elements: 5
Enter 5 elements:
10
45
23
67
32
Maximum element: 67
Minimum element: 10
```

## Algorithm

1. Read the number of elements.
2. Read all array elements.
3. Assume the first element is both maximum and minimum.
4. Compare each remaining element with the current maximum and minimum.
5. Update the values when a larger or smaller element is found.
6. Display the maximum and minimum elements.

## Time Complexity

**O(n)**

## Space Complexity

**O(n)**
